# Gate 品牌升级设计展示（最小骨架）

使用 Vue 3 + Vite + Vue Router 的最小可运行骨架：

- 持久布局：`PersistentLayout`，内含 `HeaderBar`、`SideNav`、`<RouterView/>`。
- 路由：`Home` 与 `Other` 两页，切换仅替换内容区（宽 1500）。
- 头部：高度 100px；三列占位（左 300、中 1180、右 320）；列间 1px 竖线；底部 1px full-bleed 横线。
- 导航：左侧 300 宽（文字版），内容区 1500 宽，两者并排，总宽 1800。
- 粘性（≥1500）：Logo 区固定（左 300 列），导航 sticky（贴在 Logo 下方）。
- 样式：原生 CSS + 媒体查询，集中在 `src/styles/base.css`，未引入 UI 库。

## 快速开始

1. 安装依赖：

   ```bash
   npm install
   ```

2. 启动开发服务器：

   ```bash
   npm run dev
   ```

3. 打开浏览器访问：`http://localhost:5173/`（若端口占用，Vite 会自动切换到下一个空闲端口）。

## 说明

- 头部采用三列网格布局，并在列之间加 1px 竖线，底部加 1px 横线。
- 在宽度 ≥1500 的情况下，将左侧 Logo 区固定在容器左上；侧边导航使用 `position: sticky`，`top: 100px`，紧贴 Logo 区下方。
- 内容区通过 `<RouterView/>` 渲染路由页面，切换路由仅替换内容区域。

## 响应式与断点

- 断点：`≥1800`、`1500–1799`、`1420–1499`、`1024–1419`、`≤1024`。
- `≥1800`：总宽 1800（导航 300 + 内容 1500）；头部左列固定，导航 sticky；分隔线均为真 1px。
- `1500–1799`（对向收紧）：内容区固定上限 1500，导航 300 固定；内容贴左、导航贴右，中间 `Gutter=24px`；在更窄视口会相对内收以避免溢出，文本自动换行。
- `<1500`：隐藏头部右栏、标头占满右侧；不画标头右侧竖线；导航改为 80px icon 栏；内容采用 1420 版心并继续随视口缩小。
- `1024–1419`：两列头部（左 300 + 右自适应），中间竖线保留；导航 80px；内容继续缩，左右最小内边距使用 `clamp(16px, 2vw, 24px)`。
- `≤1024`：出现 hamburger（无二级导航）；侧栏隐藏，顶部弹出菜单承载 Home/Other/下载入口（选择“进入菜单”方案）。
- 所有分隔线使用真 1px：在高分屏下通过 `border-width: 0.5px` 实现；头部底线 full-bleed。
- 导航底部常驻一个“下载小 icon”，点击有占位行为（`alert`）。

## 验收建议

请在以下典型宽度下检查布局、头部与分隔线状态：

- `2560 / 1920 / 1800`：宽屏与上限布局、固定 Logo 与 sticky 导航。
- `1536 / 1490 / 1440`：对向收紧与 `<1500` 过渡、Gutter=24。
- `1366 / 1024`：两列头部、导航 80px、内容内边距。
- `768 / 414`：hamburger 菜单，无侧栏，下载入口在菜单中。
